## 프로젝트: 📅 DMU 학기 캘린더 생성기

> 강의계획서를 붙여 넣으면 **시험·과제·발표·휴강 날짜를 자동으로 찾아** 캘린더로 만들고,
> 구글 캘린더 / 아이폰 캘린더에 바로 넣을 수 있는 **.ics 파일**로 내보내는 웹 앱

### 왜 만들었나
학기 초마다 과목별 강의계획서를 보면서 "8주차 중간고사가 몇 월 며칠이지?", "과제는 몇 주차까지였지?"를 하나하나 달력에 옮겨 적어야 합니다.
과목이 6~7개면 일정이 수십 개라 빠뜨리기 쉽습니다. 이 앱은 **주차 → 실제 날짜 변환**과 **일정 찾기**를 자동으로 해 줍니다.

### 개발 방식
1. **AI로 초기 버전 개발** — 생성형 AI(Claude)로 핵심 기능(v0.1)을 만들었습니다.
2. **커밋으로 개선** — [개선 과제](#개선-과제)를 브랜치 → 커밋 → Pull Request로 하나씩 추가합니다.

### 사용 방법
1. `index.html`을 브라우저로 엽니다. (설치 필요 없음)
2. 과목명, **개강일**, **수업 요일**을 입력합니다.
3. 강의계획서의 주차별 계획을 복사해서 붙여 넣고 **일정 만들기**를 누릅니다.
   처음이라면 **예시 불러오기**로 샘플을 먼저 넣어 보세요.
4. 과목마다 반복하면 모든 과목이 한 캘린더에 모입니다.
5. 날짜가 틀린 일정은 목록에서 바로 수정하거나 삭제합니다.
6. **.ics 파일 받기** → 구글 캘린더 `설정 → 가져오기 및 내보내기 → 가져오기`

### 현재 기능 (v0.1)
| 기능 | 설명 |
|---|---|
| 주차 인식 | `1주차`, `3주`, `제5주`, `12 \| 내용`, 표 복사(탭) 형식을 모두 인식 |
| 일정 종류 자동 분류 | **시험**(중간·기말·퀴즈), **과제**(과제·레포트·보고서·제출·마감), **발표**, **휴강**(휴강·공휴일·보강), **수업** |
| 날짜 자동 계산 | `개강 주 월요일 + (N-1)주 + 수업 요일` |
| 직접 적힌 날짜 우선 | `9/18까지`, `10.9`, `12월 3일` 처럼 날짜가 적혀 있으면 그 날짜 사용 |
| 마감 주차 인식 | `15주차까지 제출` → 15주차 수업일로 등록 |
| 여러 과목 | 과목별로 추가 · 삭제, 한 캘린더에 합쳐서 표시 |
| 월간 캘린더 | 종류별 색 구분, 종류별 보기/숨기기 필터 |
| 수정 · 삭제 | 목록에서 날짜 수정, 일정 삭제 |
| 내보내기 | `.ics` (구글·애플·아웃룩 캘린더), `.csv` (엑셀) |
| 자동 저장 | 브라우저 localStorage에 저장 → 새로고침해도 유지 |

### 동작 원리
```
강의계획서 텍스트
   │ splitWeeks()      줄마다 "N주차"를 찾아 주차별로 묶기
   ▼
주차별 내용
   │ splitPhrases()    / , · 등으로 문구 나누기
   │ detectType()      키워드로 시험·과제·발표·휴강 판별
   │ findExplicitDate()  문구 속 날짜 찾기 (없으면 weekToDate()로 계산)
   ▼
일정 목록 [{date, title, type, course, week}]
   │ toICS() / toCSV()
   ▼
학기일정.ics / 학기일정.csv
```

```
├── LICENSE                 # MIT License
└── README.md
```

## 개선 과제

| # | 개선 과제 | 난이도 | 주로 수정할 파일 |
|---|---|---|---|
| 1 | **시험·마감 알림** — .ics에 알림(VALARM) 추가. 시험 3일 전, 과제 1일 전 알림 옵션 | ★★☆ | `schedule.js`, `index.html`, 테스트 |
| 2 | **공휴일 자동 반영** — 학기 중 공휴일 목록을 넣고, 수업일이 공휴일이면 자동으로 '휴강' 표시 | ★★☆ | `schedule.js`, 테스트 |
| 3 | **수업 시간 입력** — 시작·종료 시각을 받아 하루 종일 일정 대신 시간 지정 일정으로 내보내기 | ★★☆ | `schedule.js`, `app.js`, `index.html` |
| 4 | **PDF 강의계획서 업로드** — pdf.js로 PDF에서 텍스트를 뽑아 자동 입력 | ★★★ | `app.js`, `index.html` |
| 5 | **다크 모드 · 모바일 화면 개선** | ★☆☆ | `style.css`, `app.js` |
| 6 | **GitHub Pages 배포** — 링크로 누구나 쓸 수 있게 배포하고 README에 주소 추가 | ★☆☆ | 저장소 설정, `README.md` |

진행 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.
